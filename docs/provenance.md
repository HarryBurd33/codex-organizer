# Provenance

This repository packages the original Codex Organizer workflow and metadata scanner developed for this project, under the MIT license at the repository root and inside the installed skill. The scanner's prior independent boundary tests were adapted to the portable layout. New file actions and installer are original standard-library implementations.

Official Codex documentation was consulted for skill layout/discovery and native worktree semantics. External installers and Send2Trash were inspected as design references, not copied or vendored. This package has no third-party Python dependencies and does not require Agent Forge, Skill Forge, task-checkpoint or model-switcher to run. Their private authoring/checkpoint records and user chat data are not distributed.
